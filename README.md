# Chenyu (Cheryl) Wang — personal site

## Publish on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io`.
2. Upload `index.html`, `CV_Cheryl_Wang.pdf`, a square photo named `profile.jpg` (initials show until you add it), and the `images/` folder with the school logos `umich.png`, `washu.png` and `pku.png` (colored badges show until you add them).
3. Open the repo's Settings > Pages, set Source to "Deploy from a branch" with branch `main` / root.
4. The site goes live at https://<your-github-username>.github.io within a minute or two.

To edit, change the text in `index.html`. Each section is marked with an id such as `news` or `publications`.
